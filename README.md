## Executive Summary

**MTS OFFSHORE GROUP** is an international offshore construction and marine engineering taskforce delivering complex energy infrastructure projects across the Asia-Pacific, Middle East, West Africa, and North Sea basins. Combining over 50 years of accumulated offshore leadership experience with a lean, responsive delivery framework, MTS Offshore bridges the engineering precision of Tier-1 contractors with the commercial agility required by modern energy operators.

Our operations span the entire asset lifecycle: from front-end marine consultancy and EPCI execution to subsea pipeline intervention, CALM buoy turn-key changeouts, and asset life extension.

```
 Mooring (SPM)     Installation     Engineering &      Maintenance        Management &
 Systems EPCI          (T&I)          Flowlines           (O&M)           Consultancy
```

### 1. Single Point Mooring (SPM) Systems
* **Turnkey EPCI Delivery**: Design, fabrication, transportation, positioning, and pre-commissioning of Catenary Anchor Leg Mooring (CALM) and Single Anchor Leg Mooring (SALM) buoys.
* **Overhauls & Dry-Docking**: Turn-key changeouts, main slew bearing replacements, CPU swivel refurbishments, and structural integrity renewals.
* **Mooring & Fluid Transfer Systems**: Subsea anchor leg chain tensioning, floating and submarine hose string assembly, testing, and flushing campaigns.

### 2. Transport & Installation (T&I)
* **Heavy Lift & Marine Logistics**: Transportation and installation of offshore jackets, topsides, flare booms, and subsea manifolds.
* **Float-over Operations**: Rapid deck mating and barge ballasting coordination for large topside structures.
* **Piling & Anchor Handling**: Anchor setting, driven/drilled conductors, and tension testing.

### 3. Subsea Flowlines & Pipeline Engineering
* **Pipeline & Flowline Installation**: Rigid line lay monitoring, flexible flowline deployment, umbilical tie-backs, and shore pull operations.
* **Subsea Intervention**: Diver and ROV-assisted pipeline stabilization, mattress laying, freespans correction, and subsea valve actuation.

### 4. Operations, Maintenance & Asset Integrity (AIM)
* **Integrity Audits**: Non-destructive testing (NDT), ultrasonic thickness gauging, and marine corrosion mitigation.
* **Emergency Response**: 24/7 Rapid Deployment Marine Desk for terminal emergencies, detached buoy salvage, and pipeline leaks.

### 5. Project Management & Consultancy (PMC)
* **Marine Warranty & Client Representation**: On-site representation overseeing contractor execution, rigging audits, and safety compliance.
* **Engineering Studies**: Mooring dynamic simulations, hydrodynamic analysis, and installation procedure development.

## Getting Started

### Prerequisites
* **Node.js**: `v18.17.0` or higher
* **npm**: `v9.x` or higher (or `pnpm` / `yarn`)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Vlensco/MTS-OFFSHORE.git
   cd MTS-OFFSHORE
   ```

2. **Install project dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Create a `.env.local` file in the root directory:
   ```env
   NODE_ENV=development
   DATABASE_URL=file:./data/inquiries.db
   ```

4. **Initialize Local Database** (Optional / First Run):
   ```bash
   node src/scripts/seed-db.js
   ```

5. **Start the Development Server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.
